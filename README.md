## О проекте

Проект решает задачу **Content-Based Image Retrieval (CBIR)** - поиска изображений, похожих на заданное, на основе их **визуального содержимого**, а не текстовых метаданных.

**На вход** подаётся изображение товара, **на выходе** - топ-N наиболее визуально похожих товаров из датасета.

### Ключевая идея

> Не «найди мне синюю рубашку» (по текстовому описанию), а «найди мне что-то похожее на *вот эту* рубашку» (по изображению).

### Возможности системы

- **Извлечение визуальных признаков** через предобученную VGG16 (4096-мерные эмбеддинги)
- **Поиск по косинусному сходству** среди всех изображений датасета
- **Интерактивный интерфейс** на Streamlit с фильтрами по полу и категории товаров
- **Визуализация результатов** с оценками сходства для каждого рекомендованного товара

## Подход

### 1. Извлечение признаков

Используется предобученная на **ImageNet** модель **VGG16**.

```
Входное изображение (224 × 224 × 3)
        ↓
    VGG16 (без верхнего слоя)
        ↓
    Слой fc2 → 4 096-мерный вектор признаков
        ↓
    Нормализация (preprocess_input: RGB → BGR, центрирование по ImageNet)
```

**Ключевые моменты:**
- Вход: изображение 224×224×3
- Выход: **4 096-мерный вектор признаков** (слой `fc2`)
- Предобработка: `preprocess_input` (RGB → BGR, центрирование по ImageNet)

### 2. Поиск похожих товаров

- Вычисляется **матрица косинусного сходства** между всеми эмбеддингами
- Для заданного товара выбираются **топ-N наиболее похожих**
- Сам товар **исключается** из выдачи
- Результаты сохраняются в файл `top_similar_images.json`

### 3. Оценка качества

- **Визуальная проверка** релевантности выдачи
- **Средняя схожесть топ-4 товаров:** 81–86%

## Как работает приложение

Приложение (`recsis_app.py`) — это **визуальная демонстрация** уже готовых рекомендаций. Все вычисления (VGG16 → эмбеддинги → косинусное сходство) выполняются заранее, а результат сохраняется в `top_similar_images.json`.

### Схема работы

```
1. Загрузка данных (load_data)
   ├── styles.csv                  → метаданные товаров
   ├── top_similar_images.json     → предрассчитанные рекомендации
   └── папка images/               → сами картинки
                │
                ▼
2. Пересечение: товары, у которых есть И картинка, И рекомендации
                │
                ▼
3. Интерфейс
   ├── Сайдбар: фильтры (пол, категория)
   ├── Сетка 30 товаров (4 колонки) с кнопками выбора
   └── При клике → блок с 4 рекомендациями
```

### Интерфейс

1. **Сайдбар с фильтрами:**
   - **Пол** (`gender`): Все / Men / Women / Unisex / Kids
   - **Категория** (`articleType`): Все / Shirts / Jeans / Casual Shoes / ...

2. **Сетка товаров** — первые 30 отфильтрованных товаров в 4 колонки. Под каждым товаром:
   - Кнопка с его ID
   - Изображение
   - Подпись: тип товара и базовый цвет

3. **Блок рекомендаций** — появляется при клике на ID любого товара. Показывает:
   - Выбранный товар (слева)
   - **Топ-4 визуально похожих товара** с оценками сходства
