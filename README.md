# Visual Similarity Search for Fashion Products

Система поиска визуально похожих товаров на основе извлечения признаков свёрточной нейронной сети (VGG16) и косинусного сходства.

## О проекте

Проект решает задачу **Content-Based Image Retrieval (CBIR)** - поиска изображений, похожих на заданное, на основе их визуального содержимого, а не текстовых метаданных.

На вход подаётся изображение товара, на выходе - топ-N наиболее визуально похожих товаров из датасета.

## Данные

**Fashion Product Images Dataset** (Kaggle):
- 2 457 изображений товаров
- 44 424 записи с метаданными (категория, пол, сезон, цвет, тип товара)

**Пример метаданных:**

| id | gender | masterCategory | subCategory | articleType | baseColour | season |
|---|---|---|---|---|---|---|
| 15970 | Men | Apparel | Topwear | Shirts | Navy Blue | Fall |
| 39386 | Men | Apparel | Bottomwear | Jeans | Blue | Summer |

## EDA и визуализация

В ходе анализа данных:
- Проанализировано распределение товаров по полу, категориям, сезонам и типам
- Выявлено, что большинство товаров — одежда (Apparel)
- Установлено, что 3/4 товаров покупаются летом и осенью
- Определены топ-категории: футболки, рубашки, повседневная обувь

**Визуализации:**
- Распределение товаров по полу
- Топ категорий
- Зависимость количества покупок от сезона
- Топ-15 типов товаров

## Подход

### 1. Извлечение признаков

Используется предобученная на ImageNet модель **VGG16**:
- Вход: изображение 224×224×3
- Выход: 4 096-мерный вектор признаков (слой `fc2`)
- Предобработка: `preprocess_input` (RGB → BGR, центрирование по ImageNet)

### 2. Поиск похожих товаров

- Матрица косинусного сходства между всеми эмбеддингами
- Для заданного товара выбираются топ-N наиболее похожих
- Исключается сам товар из выдачи

### 3. Оценка

- Визуальная проверка релевантности выдачи
- Средняя схожесть топ-4 товаров: **81–86%**
